## 1. 整体架构

### 1.1 模块划分

```
┌─────────────────────────────────────────────────────────────┐
│                         main.c                              │
│                      (系统入口)                              │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│  矩阵    │  编码器   │   LED    │  Profile │   串口命令      │
│  驱动    │  驱动     │   驱动   │  存储    │   解析         │
│          │          │          │          │                 │
│ matrix_  │ encoder_ │ led_     │ profile_ │ serial_        │
│ driver   │ driver   │ driver   │ store    │ cmd            │
├──────────┴──────────┴──────────┴──────────┴─────────────────┤
│                     HID 管理器                              │
│                    (hid_manager)                             │
├─────────────────────────────────────────────────────────────┤
│           USB HID            │          BLE HID             │
│         (usb_hid)           │         (ble_hid)            │
└──────────────────────────────┴──────────────────────────────┘
```

### 1.2 数据流向

```
矩阵 ISR ─→ 按键事件队列 ─→ main_task ─→ keymap ─→ HID 管理器 ─→ USB/BLE
                                                              │
编码器 ISR ─→ 编码器事件队列 ─→ main_task ─→ 音量控制 ─────────┘
                                               │
LED 事件队列 ←─────────────────────────── led_task ─→ LED 硬件
                                               │
串口输入 ←──────────────────────────── serial_task ─→ 命令处理
```

### 1.3 任务间通信

| 生产者 | 消费者 | 通信方式 |
|--------|--------|----------|
| 矩阵 ISR | matrix_task | Queue (key_event_t) |
| 编码器 ISR | main_task | Queue (encoder_event_t) |
| 串口输入 | serial_task | stdin |
| 命令处理 | led_task | Queue (led_event_t) |
| HID 管理器 | USB/BLE | 函数调用 |

## 2. 各模块设计

### 2.1 矩阵扫描 (matrix_driver)

**原理**：
- 4×5 矩阵，19 键 + 1 个 2u 空格
- 列（COL）输出，逐列驱动高电平
- 行（ROW）输入，下拉读取
- 二极管方向：行→列（阳极→行，阴极→列）

**扫描流程**：
```
硬件定时器 ISR（每 5ms 触发）
├── 拉高当前列
├── 等待 1us 电平稳定
├── 读取所有行
├── 记录状态变化
├── 拉低当前列
└── 切换到下一列

matrix_task（每 5ms 执行）
├── 检查每个键的状态变化
├── 防抖确认（20ms）
├── 创建按键事件
└── 发送到事件队列
```

**防抖策略**：
- 软件防抖，20ms 时间窗口
- 状态变化后等待 20ms 再确认
- 避免机械抖动导致的误触发

### 2.2 编码器解码 (encoder_driver)

**原理**：
- EC11 旋转编码器，A/B 相 + 按键
- 四倍频解码：每个脉冲的上升沿和下降沿都计数
- 状态表查表：(old_state << 2) | new_state

**解码流程**：
```
GPIO 中断（A/B 相任何边沿）
├── 读取 A/B 相状态
├── 计算新状态
├── 查表得到方向
├── 更新状态
└── 发送旋转事件

GPIO 中断（按键）
├── 读取按键状态
├── 防抖处理
└── 发送按键事件
```

**状态表**：
```c
encoder_table[16] = {
     0, +1, -1,  0,  // 0000, 0001, 0010, 0011
    -1,  0,  0, +1,  // 0100, 0101, 0110, 0111
    +1,  0,  0, -1,  // 1000, 1001, 1010, 1011
     0, -1, +1,  0,  // 1100, 1101, 1110, 1111
};
```

### 2.3 LED 控制 (led_driver)

**LED 语义**：
- 常亮：当前模式（USB=白，BLE=蓝，2.4G=绿）
- 慢闪（1Hz）：低电（<3.55V）
- 快闪 N 次：切换 Profile N
- 快闪（5Hz）：配对中

**实现**：
- 低电平点亮：0=ON，1=OFF
- LED 任务根据当前模式控制闪烁
- 事件驱动：通过队列接收控制命令

### 2.4 HID 管理器 (hid_manager)

**设计原则**：
- 延迟初始化：同一时间只初始化一个 HID 接口
- 动态切换：支持运行时切换模式
- 错误恢复：初始化失败时回退到旧模式

**切换流程**：
```
切换模式
├── 获取互斥锁
├── 反初始化当前模式
│   ├── USB: tinyusb_driver_uninstall()
│   └── BLE: nimble_port_deinit()
├── 等待 100ms
├── 初始化新模式
│   ├── USB: tinyusb_driver_install()
│   └── BLE: nimble_port_init() + nimble_port_freertos_init()
├── 更新 LED 状态
├── 释放互斥锁
└── 错误处理：失败时回退到旧模式
```

### 2.5 USB HID (usb_hid)

**HID 描述符**：
- 键盘：6 键无冲 + 修饰键 + LED
- Consumer Control：Volume Up/Down

**TinyUSB 配置**：
- VID: 0x303A (Espressif)
- PID: 0x4002
- 设备名：SimpleKey Tri-mode

### 2.6 BLE HID (ble_hid)

**NimBLE 配置**：
- HID over GATT 服务
- 3 个配对槽位，独立虚拟 MAC
- 自动重连上次配对的设备

**槽位管理**：
- 每个槽位存储：设备名、MAC、配对状态
- NVS 持久化存储
- 切换槽位时自动重连

### 2.7 Profile 存储 (profile_store)

**Profile 结构**：
```c
typedef struct {
    char name[16];          // Profile 名称
    uint8_t keymap[5][4];   // 键位映射
    uint8_t default_mode;   // 默认连接模式
    bool valid;             // 是否有效
} profile_t;
```

**NVS 存储**：
- 键：`profiles`
- 值：3 个 Profile 的 blob 数据
- 当前索引单独存储

### 2.8 串口命令 (serial_cmd)

**命令格式**：
```
<命令> [参数1] [参数2] ...
```

**命令列表**：
- 系统：help, version, status, reboot, factory
- 模式：mode, mode usb/ble/next
- Profile：profile, profile next, profile set N
- 键位：keymap
- LED：led usb/ble/2g4 on/off
- 编码器：enc

**实现**：
- 状态机解析
- 支持退格编辑
- 历史记录（预留）

## 3. 任务优先级配置

| 任务 | 核心 | 优先级 | 栈大小 | 说明 |
|------|------|--------|--------|------|
| matrix_task | Core 1 | 18 | 2048 | 矩阵扫描（硬件定时器 ISR 驱动） |
| encoder_task | Core 0 | 11 | 2048 | 编码器解码（GPIO 中断） |
| main_task | Core 0 | 10 | 4096 | HID 事件处理 |
| serial_task | Core 0 | 5 | 2048 | 串口命令处理 |
| led_task | Core 0 | 3 | 1024 | LED 状态指示 |

**核心分配原则**：
- Core 0：通信任务（USB、BLE、串口）
- Core 1：输入任务（矩阵、编码器）

## 4. 数据结构

### 4.1 按键事件结构体
```c
typedef struct {
    uint8_t row;            // 行号
    uint8_t col;            // 列号
    uint8_t key_code;       // HID 键码
    key_event_type_t type;  // 事件类型
    int64_t timestamp;      // 时间戳
} key_event_t;
```

### 4.2 编码器事件结构体
```c
typedef struct {
    encoder_event_type_t type;  // 事件类型
    int8_t delta;               // 旋转增量
    bool button_state;          // 按键状态
    int64_t timestamp;          // 时间戳
} encoder_event_t;
```

### 4.3 Profile 结构体
```c
typedef struct {
    char name[16];          // Profile 名称
    uint8_t keymap[5][4];   // 键位映射
    uint8_t default_mode;   // 默认连接模式
    bool valid;             // 是否有效
} profile_t;
```

### 4.4 HID 报告结构体
```c
// 键盘报告（6 键无冲）
typedef struct {
    uint8_t modifiers;      // 修饰键
    uint8_t reserved;       // 保留
    uint8_t keys[6];        // 键码
} __attribute__((packed)) hid_keyboard_report_t;

// Consumer Control 报告
typedef struct {
    uint16_t usage_code;    // 使用码
} __attribute__((packed)) hid_consumer_report_t;
```

## 5. 初始化流程

```
app_main()
├── 1. NVS Flash 初始化
├── 2. Profile 初始化（包含 keymap）
├── 3. 矩阵扫描初始化
│   ├── GPIO 配置
│   ├── 硬件定时器配置
│   └── 事件队列创建
├── 4. 编码器初始化
│   ├── GPIO 配置
│   ├── 中断服务安装
│   └── 事件队列创建
├── 5. LED 初始化
│   ├── GPIO 配置
│   ├── 事件队列创建
│   └── LED 任务创建
├── 6. 串口命令初始化
├── 7. HID 管理器初始化
├── 8. 根据默认模式初始化 HID（默认 BLE）
├── 9. 启动矩阵扫描
├── 10. 设置 LED 为当前模式常亮
├── 11. 创建主任务
└── 12. 创建串口任务
```

## 6. 调试方法

### 6.1 串口日志

```bash
# 编译
build.bat

# 烧录
build.bat flash COM3

# 监控
build.bat monitor COM3
```

### 6.2 日志级别策略

| 级别 | 用途 | 示例 |
|------|------|------|
| `ESP_LOGE` | 错误/崩溃 | 初始化失败、NVS 错误 |
| `ESP_LOGW` | 警告/状态异常 | 连接断开、模式切换失败、队列满 |
| `ESP_LOGI` | 关键状态变化 | 模式切换成功、连接建立/断开、首次启动 |
| `ESP_LOGD` | 运行时调试 | 按键按下、编码器按键、模块初始化进度 |
| `ESP_LOGV` | 高频调试 | 编码器旋转（默认不显示） |

**各模块日志策略**：

| 模块 | 初始化 | 运行时 | 说明 |
|------|--------|--------|------|
| main | LOGI（banner 2行） | LOGD（按键/编码器事件） | 启动精简 |
| matrix | LOGD（配置信息） | LOGD（按键按下） | 只在按下时输出 |
| encoder | LOGD（引脚配置） | LOGV（旋转）/ LOGD（按键） | 旋转默认不显示 |
| led | LOGD（初始化） | 无 | LED 任务不输出日志 |
| hid_manager | LOGD（初始化） | LOGI（模式切换成功） | 关键变化保留 |
| ble_hid | LOGD（初始化） | LOGI（连接/断开） | 连接状态保留 |
| usb_hid | LOGD（初始化） | LOGI（mount/unmount） | 连接状态保留 |
| serial_cmd | LOGD（初始化） | LOGD（命令执行） | 用户命令通过 printf 输出 |

### 6.3 LED 指示

| LED 颜色 | 状态 |
|----------|------|
| 白色常亮 | USB 模式 |
| 蓝色常亮 | BLE 模式 |
| 绿色常亮 | 2.4G 模式 |
| 蓝色快闪 | BLE 配对中 |
| 蓝色慢闪 | 低电 |
| 蓝色快闪 N 次 | 切换到 Profile N |

```bash

# 切换模式

> mode ble

# 查看键位

# 查看编码器
```

### 6.5 常见问题

**问题 1：BLE 和 USB 冲突**
- 原因：PHY 初始化冲突
- 解决：使用延迟初始化，同一时间只初始化一个

**问题 2：按键无响应**
- 原因：矩阵扫描未启动
- 检查：确认 matrix_start() 已调用

**问题 3：编码器计数不准**
- 原因：中断未正确配置
- 检查：确认 GPIO 中断已安装

**问题 4：LED 不亮**
- 原因：GPIO 配置错误或极性错误
- 检查：确认使用低电平点亮

## 7. 扩展指南

### 7.1 添加新按键

1. 在 `keymap.c` 的 `default_keymap` 中添加键码
2. 在 `keymap.h` 中添加键码定义（如果需要）

### 7.2 添加新命令

1. 在 `serial_cmd.c` 的 `process_cmd()` 中添加命令处理
2. 在 `print_help()` 中添加帮助信息

### 7.3 添加新 Profile

1. 在 `profile_store.c` 的 `default_profile` 中添加默认值
2. 修改 `PROFILE_COUNT` 增加 Profile 数量

### 7.4 添加新 LED 效果

1. 在 `led_driver.h` 中添加新的 LED 模式
2. 在 `led_task` 中添加对应的处理逻辑
